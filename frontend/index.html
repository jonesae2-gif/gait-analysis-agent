A biomedical AI agent that learns from you

GaitMind combines a multi-step reasoning pipeline with a lightweight cognitive-learning memory. Upload gait data, watch the Planner, Analyzer, and Critic agents collaborate, and teach the system to get better with every piece of feedback.

Upload gait data → Learn how the AI agent works

Multi-agent reasoning

A Planner picks the right modules, an Analyzer crunches the biomechanics, and a Critic challenges the result before you see it.

Real biomechanics

Step-time variability, Robinson symmetry index, harmonic ratio, cadence — clinically-inspired metrics with transparent formulas.

Cognitive learning

Mark predictions correct or incorrect and the system adjusts feature weights, thresholds, and memory in real time.

Reasoning trace

Every decision is shown step-by-step so you can audit how the agent reached its conclusion — no black box.

Try it in 30 seconds

  1. Open the Analysis page.
  2. Click Use sample dataset (or upload your own CSV / enter parameters manually).
  3. Inspect the reasoning trace and the abnormality meter.
  4. Click This is correct or This is incorrect — the memory panel updates instantly.
