Agent architecture

GaitMind orchestrates three specialized agents that pass structured messages to each other. The pipeline is deterministic, so it can run without an external LLM, but every agent exposes a clean interface so a real LLM call can be dropped in at any layer.

1 · Planner

Reads the request shape (CSV columns or manual fields) and emits a plan: which analysis modules to run, in what order, and why.

2 · Analyzer

Executes the plan. Computes variability, symmetry, harmonic ratio, and cadence; combines them with memory-driven weights into a 0–100 abnormality score.

3 · Critic

Reviews the Analyzer's reasoning, flags borderline scores, sparse-data warnings, and conflicts between strong individual features and the overall label, then writes the final explanation.

Every agent's intermediate output is shown verbatim in the reasoning trace on the Analysis page — there is no hidden state.

Cognitive learning loop

The system maintains a JSON memory file that captures three things: feature weights, dynamic thresholds, and a tally of which features have historically correlated with each user-confirmed label.

What changes on feedback

False positive (we said abnormal, you say normal)
Down-weight the loudest contributing features; raise the abnormality cutoff slightly.
False negative (we said normal, you say abnormal)
Up-weight the elevated features; lower the cutoff slightly.
Agreement
No weight change, but the agreement counter ticks up so confidence in the system's calibration grows.
Always
Increment the per-feature, per-label correlation tally — the Critic uses this to add experiential context to future predictions.

Updates use a small learning rate (Δ ≈ 0.10 × contribution) and weights are clamped to [0.1, 3.0] so the system can't run away after one bad example. Think of it as a hand-rolled, interpretable cousin of an online gradient update.

Gait biomechanics, briefly

Step-time variability

The coefficient of variation of consecutive step intervals. Healthy adults are typically below ~3% CV; values above ~10% are associated with elevated fall risk in older adults.

Robinson symmetry index

SI = |L − R| / (½(L + R)) × 100. A perfectly symmetric walker scores 0%; values above ~15% are commonly seen with post-stroke hemiparesis or unilateral pain.

Harmonic ratio

Computed from the FFT of vertical acceleration: the ratio of even-harmonic to odd-harmonic power. Higher values mean a smoother, more periodic gait pattern.

Cadence

Steps per minute, derived from the average inter-step interval. A typical adult walks at 95–125 steps/min; values well outside that band can indicate compensation or pathology.

Limitations & ethics

GaitMind is a teaching demo, not a medical device. The reference ranges are simplified; real clinical assessments require instrumented walkways, multiple trials, and expert interpretation. The cognitive-learning memory is shared across all users on a given deployment — production use would require per-user partitioning, access controls, and audit logging.

Bias risk: if the only feedback the system ever receives comes from one demographic (e.g. healthy young adults), its weights and threshold will drift toward that population's norms. We recommend resetting memory before any new study and surfacing the agreement/disagreement counters to anyone interpreting results.
